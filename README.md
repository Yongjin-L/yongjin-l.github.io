# Yongjin Lee - Personal Academic Website

[![Website Status](https://img.shields.io/website?url=https%3A%2F%2Fyongjin-l.github.io)](https://yongjin-l.github.io)

This is the personal academic website of **Dr. Yongjin Lee**, an educator and researcher specializing in physical education, reflective practice, and AI-enhanced education.

🌐 **Live Site**: [https://yongjin-l.github.io](https://yongjin-l.github.io)

## 📚 Website Overview

This website showcases academic work, research, and educational innovations:

- **[About](about/index.qmd)**: Personal background, core expertise, and professional journey
- **[Research](research/index.qmd)**: Academic research, publications, and scholarly contributions
- **[Teaching](teaching/index.qmd)**: Teaching philosophy, experience, and educational approaches
- **[AI in Education](ai_in_edu/index.qmd)**: Innovative applications of AI in educational contexts, including:
  - Teacher reflective practice with AI-powered pedagogy
  - Qualitative data analysis using RAG and topic modeling
  - Graph knowledge-enhanced literature review systems
- **[CV](cv.qmd)**: Academic curriculum vitae

## 🛠 Technical Stack

This website is built with [Quarto](https://quarto.org), an open-source scientific and technical publishing system that enables the creation of dynamic, reproducible content.

### Key Technologies:
- **[Quarto](https://quarto.org)**: Static site generator and publishing system
- **HTML/CSS/SCSS**: Custom styling with brand theming (`assets/jin-theme.scss`)
- **Bootstrap & Cosmo Theme**: Responsive UI framework
- **GitHub Pages**: Hosting and deployment
- **Utterances**: Comment system for visitor engagement
- **Google Analytics**: Site analytics (G-CTZK0CZZXG)
